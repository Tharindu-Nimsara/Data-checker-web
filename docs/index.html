Why use the Widget?

📊

Precision Tracking

  • ⏱️ Real-Time Usage Monitoring: Check your broadband usage instantly right on your desktop, completely eliminating the need to log into a clunky web browser.
  • 🎛️ Custom Data Filtering: Don't care about "Free Data" or "Bonus Data"? The Settings UI lets you dynamically toggle exactly which of the 5 standard data categories you want visible.
  • 🔄 Flexible Sync Intervals: Choose how aggressively the widget pulls updates (from every 15 minutes to every 3 hours), or switch to Manual Mode to save bandwidth.
🛡️

Privacy & Security First

  • 🕶️ "Hide Details" Privacy Mode: Worried about shoulder surfers? A single click inside the Quick Menu instantly collapses and hides your exact data numbers, package names, and texts into a purely visual progress bar.
  • 🔐 Aggressive Data Security: Your password NEVER touches a vulnerable text file. It is encrypted and locked securely inside the native Windows Credential Manager.
  • 🚫 Zero Telemetry: 100% Free and Open Source. The widget does absolutely no tracking, has no analytics, and does not collect a single byte of your data.
🔔

Smart Operating System Hooks

  • 💬 Windows Action Center Toasts: Set a custom "Low Data" threshold (e.g. 5.0 GB), and the widget will fire a native Windows push notification to warn you before you run out.
  • 🧠 Cycle-Aware Alerts: The notification engine is smart enough to detect when a new billing month starts or a new Add-On is purchased, automatically resetting your warning threshold for you.
  • 🚀 Silent Windows Autostart: Flip a 1-click setting to hook the widget into your Windows Registry, allowing it to seamlessly and silently boot in the background every time you turn on your PC.
🎨

Premium UI/UX

  • ✨ Zero-Clutter Floating Interface: An incredibly minimalist widget footprint that remembers its exact X/Y screen coordinates across computer restarts.
  • ⚡ Dynamic Quick Menu: Right-click the widget to instantly access privacy features, refresh controls, and settings without opening large software windows.
  • 🤖 Automated API Handshake: Users don't need to be developers to use this. The widget secretly scrapes the live provider portal behind the scenes to automatically unearth the required authentication keys on the fly!
